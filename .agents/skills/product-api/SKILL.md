# Skill: Producto API

Use esta guía al modificar la capacidad de productos.

1. Lea `user-stories/US-001-register-product.md`.
2. Lea `openspec/specs/products/spec.md` y el cambio activo aplicable.
3. Mantenga el flujo Controller → Service → Repository.
4. Actualice pruebas y contrato OpenAPI cuando cambie un endpoint.
5. Ejecute `mvn test` y `openspec validate --all` antes de finalizar.
